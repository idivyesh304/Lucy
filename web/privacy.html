Lucy · Privacy policy

Lucy is a personal assistant app used privately by its owner, Divyesh Panchal.

Google Drive. Lucy asks only for access to its own hidden app folder in the user's Google Drive (the drive.appdata permission). It uses that folder to save and restore the user's own Lucy data and daily backups. Lucy cannot see, read or change any other file in Google Drive.

Where data goes. Lucy's data stays on the user's device, in the user's own Google Drive app folder, and in the user's own private helper service. It is never sold, shared or used for advertising. When the user asks Lucy an AI question, that message is sent to the AI provider the user chose (Anthropic or OpenAI) to get an answer.

Removing access. The user can disconnect Google Drive at any time in Lucy, or at myaccount.google.com/permissions.
